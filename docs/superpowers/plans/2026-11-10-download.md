# Current-episode MP4 implementation plan

Goal: implement the selected MP4 download on Windows without disturbing the foreground.
Architecture: native task manager + temporary capability-protected loopback media
server sharing TicketStore + FFmpeg copy/remux + global progress card.

1. Add native download module with status, filename and argument helpers. Test
   sanitization/path safety, protocol restriction and progress parsing before implementation.
2. Reserve one task atomically, resolve FFmpeg, prepare a fresh ticket using an
   ephemeral server prefix; spawn FFmpeg with argument arrays. Poll progress, cap
   duration/runtime, support cancellation and safe finalization.
3. Expose a native-only player button and global status/cancel/open-folder card.
4. Add companion installer and docs. Verify synthetic encrypted HLS export,
   MP4 streams/duration, cancellation cleanup and existing suites without browser automation.
5. Review, commit/push and build an updated client in the background. Leave the
   running foreground client alone; provide the new executable/package for next restart.
